<!-- ENTIDADE - VALIDAR DADOS COMPLETOS -->

Ao gravar uma entidade, confere se os dados principais (endereço, documentos, etc.) estão preenchidos e impede a gravação se faltar algo.

- **SIM**: cadastro só grava completo.
- **NÃO**: permite gravar com dados parciais.
