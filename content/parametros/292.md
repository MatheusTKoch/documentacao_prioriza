<!-- SISTEMA - IP + PORTA API ATUALIZACAO -->

Endereço (IP ou nome) e porta do serviço que distribui as atualizações do sistema. Usado pela tela de atualização automática para baixar a versão nova.

Formato: `endereco:porta`. Só altere com orientação do suporte.
