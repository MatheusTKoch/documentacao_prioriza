<!-- PEDIDO VENDA - NAO VERIFICAR SE JA EXISTE ORDEM DE PRODUCAO PARA OS ITENS DO PEDIDO -->

Ao gerar ordem de produção a partir do pedido, define se o sistema deixa de verificar se já existe ordem para os mesmos itens.

- **SIM**: não verifica (pode gerar ordens duplicadas).
- **NÃO**: avisa se já houver ordem.
